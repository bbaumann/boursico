# Project Instructions

## User-Facing Language

- All operator-facing UI labels, page titles, buttons, validation messages, and helper text must be written in French.
- All user-facing application routes and URLs must be written in French.
- Internal code identifiers, file names, class names, and canonical technical documentation may remain in English unless a future spec says otherwise.

## Shell Commands

- Follow the local `RTK` rule for shell commands when working in this repository.
